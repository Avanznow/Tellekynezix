## Data, inputs and protocols

- **Windows.** 11,698 windows (≤ 2000 per command, seed 0; with 2000 per command this is the subsample of the original `prediction-quantum` benchmark) of the project's 570-feature cache (verified loader, 128-sample windows, stride 64, 15 channels at 125 Hz; `features_4df6a3d7e7044283.npz`).
- **Inputs.** Per fold, StandardScaler + PCA to 6 components + percentile angle map to [0, π] (the project's `FeatureEncoder`), fitted on the training part only; the quantum models and the angle baselines see exactly these angles. The `(570)` baselines see the 570 standardized features.
- **Protocols.** participant: Participant-independent (GroupKFold by participant); recording: Recording-grouped (seeded splits of the original benchmark). Validation recordings are taken from the training part of each fold and used only to choose the checkpoint of the VQC and the MLPs. Leakage checks (no recording, and in the participant protocol no participant, on two sides) passed for every fold.
- **Quantum kernel SVM.** ZZ feature map on a ring of 6 qubits, 2 repetitions, fidelity kernel from exact statevectors, SVC (C = 1.0) on a stratified training subsample of at most 3000 windows; the RBF SVM uses the same subsample.
- **VQC.** The project's classifier (`prediction_quantum/vqc.py`): RY angle embedding, 4 StronglyEntanglingLayers, Pauli-Z readout, linear head; Adam (lr 0.01), batch 64, 40 epochs, best-validation checkpoint.
- **No hyperparameter tuning** for any model; every model uses fixed, documented settings.

## Limitations

- Simulation only: exact statevectors, no shot noise, no device noise, no queueing; latencies are CPU wall time of a Python call on this machine and say nothing about hardware execution.
- Dimensionality: angle encoding uses one PCA component per qubit, so the circuits see a few components of the 570 features; exact simulation cost grows as 2^n with the number of qubits and the kernel cost as n_train^2, which is why the kernel models use a training subsample.
- No hyperparameter search for any model, a single feature map and a single ansatz.
- Few folds (5 and 3); standard deviations mix split and initialization variance.
- The recording-grouped protocol measures within-session separability on a block-design dataset (paper, Section 3.4); only the participant-independent protocol speaks to a new user.
- The benchmark is offline and independent of the real-time drone-control pipeline; no model here was integrated into the GUI.
